Version History

Changelog

A record of every release of SQL Visualizer — what changed, what was added, and what was fixed. Versions are listed most recent first.

For new feature suggestions, vote here

v1.4

April 2026
Latest
Minor Release - Early April

A polish and expansion release. The interface now supports a light theme alongside dark mode, the homepage was redesigned for clarity, and the joins page gained toast notifications for better feedback. New dataset options enable set operator practice, security hardening improves privacy, and community voting for features is now live.
Overall improvements across visual design, security, and user engagement.

  • Added a light theme with dark mode toggle
  • Redesigned the main homepage for clarity and ease of navigation
  • Improved website security and privacy across all pages
  • Introduced a new dataset optimized for join and set operator practice
  • Added toast messages on the joins page for better UX feedback
  • Enabled community voting for new features via GitHub issues

v1.3

April 2026
Major Release - Early April

A substantial overhaul across the board. The SQL engine was rewritten from scratch to handle joins and set operators reliably, the Generated SQL panel was introduced with live output, and the Execution Order visualizer was added as a new standalone page.
The overall visual language was refreshed and the page structure simplified throughout.

  • Introduced the Generated SQL panel. A live code block that reflects the current join configuration, with a one-click copy button.
  • Rewrote the SQL engine to support JOINS and SET OPERATORS
  • Added two pre-loaded sample datasets in pages [01] covering common patterns.
  • New Execution Order page with an 12-step expandable timeline
  • Sidebar groups now labelled and separated by section
  • Refreshed typography and theme overall.
